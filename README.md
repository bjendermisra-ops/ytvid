# BhaktiTube — Shree Shree Radha Krishna Chandra Mandir

Premium devotional video web app for Android WebView and mobile browsers.

- **index.html** — self-contained HTML, CSS and JavaScript, featuring embedded YouTube player and devotional video catalog.
- **assets/** — decorative SVG images, thumbnails fallback, seasonal artwork.
- **Layout:** default YouTube-inspired 1-column feed; Settings offers 2-column grid, saved locally.
- **Languages:** Hindi, English and Marathi interface options.

To preview, open `index.html` with a browser (YouTube embedding and playback may depend on HTTPS/Android WebView policies).

Copyright on third-party YouTube thumbnails and videos belongs to their respective owners. The app uses links/embeds; it does not mirror YouTube media.
